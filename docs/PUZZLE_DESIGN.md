# 퍼즐 설계

## 공통 원칙

- 한 방에 퍼즐 8~12단계, 초등학생 기준 15~25분.
- 능력 골고루: 관찰 · 창의(조합) · 넌센스 · 논리 · 공간지각 · 도구 활용.
- 지시서의 다섯 가지 장치를 다섯 방에 나눠 꼭 한 번 이상 쓴다: 거울 글자, 그림자 암호, 아이템 조합, 예상 밖의 쓰임, 환경 변화.
- 단서는 반드시 방 안에 보인다. 정답을 들으면 "아, 그래서!" 하고 납득되어야 한다.
- 막히면 3단계 힌트: ① 어디를 볼지 ② 무엇을 생각할지 ③ 정확히 무엇을 할지.
- 잘못 써도 벌칙 없음. 왜 안 되는지 짧게 알려 준다 ("자석만 던지면 물속으로 사라질 거야").

## 1장 햇살이 멈춘 온실 (구현 완료)

**이야기**: 온실의 해님 기계가 깊이 잠들어 시간이 멈췄다. 해님을 깨워야 꽃이 자라고, 해바라기가 지키는 열쇠로 문을 열 수 있다.

**벽 4개**: 북(문, 해바라기 화단, 큰 화분, 뜨개 바구니, 달팽이 정원사) · 동(작업대, 선반, 숫자 액자) · 남(해님 기계, 안내판) · 서(빗물통, 새장, 도구 걸이)

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 북쪽 뜨개 바구니에서 **실타래** | 관찰 | |
| 2 | 동쪽 선반 가운데 화분만 튀어나와 있음 → 기울이면 **손거울** | 관찰 | |
| 3 | 액자 숫자가 좌우로 뒤집혀 있고, 구석에 손거울 그림과 ↔ 표시 → 거울로 비추면 **352** | 거울 | 거울은 좌우를 바꾼다 |
| 4 | 작업대 서랍 3자리 다이얼 352 → **말굽자석**, **해바라기 씨앗** | 논리 | |
| 5 | 자석 + 실타래 = **자석 낚싯줄** | 조합 | |
| 6 | 서쪽 빗물통 바닥 반짝임(손 넣기엔 깊음) → 낚싯줄로 **태엽 열쇠** | 예상 밖의 쓰임 | 자석은 쇠를 끌어당긴다 |
| 7 | 서쪽 새장 열기 → **양철 수탉** (등에 구멍) | 관찰 | |
| 8 | 태엽 열쇠 + 수탉 = **태엽 감은 수탉** | 조합 | |
| 9 | 안내판 "해님의 알람시계는 누구?" → 수탉을 해님에게 → 꼬끼오! | 넌센스 | 해 뜨면 닭이 운다 |
| 10 | **환경 변화**: 방 전체가 아침이 됨. 해바라기가 고개를 들고, 어두워서 안 보이던 작업대 밑 **물뿌리개**가 보임 | 환경 변화 | |
| 11 | 물뿌리개 → 빗물통에서 물 채우기 | 도구 활용 | |
| 12 | 큰 화분에 씨앗 심고 물 주기 → 햇빛까지 있으니 해바라기가 쑥쑥 → 꽃 가운데 **해바라기 열쇠** | 논리 | 식물은 흙·물·햇빛으로 자란다. 쪽지: "열쇠는 해님을 닮은 꽃이 지킨다" |
| 13 | 문 자물쇠가 해바라기 모양 → 열쇠로 탈출 | 관찰 | |

## 2장 토끼의 장난감 공방 (구현 완료)

**이야기**: 장난감 장인 토끼 모카의 공방에 놀러 왔는데, 모카가 낮잠을 자는 사이 문이 잠겼다. 문에 붙은 쪽지: "깨우지 마세요… 단, 생일 노래는 예외!"

**벽 4개**: 북(모카의 안락의자, 깜짝 상자, 당근 자물쇠 문, 모카 옆모습 그림) · 동(작업대, 빨간 작업등, 그림자 인형극 무대, 쥐구멍) · 남(커튼 친 창문, 장난감 선반, 치즈 병, 흔들 목마) · 서(재봉틀, 자수 악보, 토마토 바늘꽂이, 반짇고리 통, 마네킹)

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 동쪽 빨간 작업등 켜기 → 인형극 화면에 빛 | 환경 변화 | 그림자는 빛이 있어야 생긴다 |
| 2 | 나무 조각 셋(몸·머리·귀)을 90도씩 돌려 **토끼 그림자** 만들기 → 무대 서랍에서 **고무줄** | 공간지각·그림자 | 카드와 북쪽 벽 모카 그림이 정답 모양 |
| 3 | 남쪽 치즈 병: 뚜껑이 미끄러워 안 열림 → 고무줄을 감아 열기 → **치즈** | 예상 밖의 쓰임 | 실제 생활 요령 |
| 4 | 동쪽 쥐구멍의 생쥐 찍찍이(등 뒤에 손잡이를 숨기고 배고파함)에게 치즈 → **태엽 손잡이** | 관찰 | |
| 5 | 서쪽 바늘꽂이 → **시침핀**, 반짇고리 통 → **실뜯개** | 관찰 | |
| 6 | 북쪽 깜짝 상자: 옆 구멍에 손잡이 끼우기, 원통에 핀 쓰기 | 도구 | 돌려 보면 노래가 끊겨서 핀이 부족함을 알 수 있다 |
| 7 | 서쪽 자수 악보의 별 높이(아래·가운데·위·가운데·아래·위)대로 원통에 핀 꽂고 손잡이 돌리기 | 관찰·논리 | 악보 = 오르골 원통, 줄 3개 = 칸 3줄 |
| 8 | **환경 변화**: 생일 노래 → 깜짝 상자 펑! → 모카가 깨어나고 커튼이 열려 방이 환해짐 | 환경 변화 | 쪽지 "생일 노래는 예외" |
| 9 | 모카: "문 열쇠? 그건… **당근이지!**" → 당근 인형을 받음 (등에 바느질 자국, 속에 딱딱한 것) | 넌센스 | '당근이지' = '당연하지' 말장난 |
| 10 | 당근 인형 + 실뜯개 = **당근 열쇠** → 당근 자물쇠 문 열고 탈출 | 조합 | |

## 3장 열세 번째 시계 (구현 완료)

**이야기**: 밤 12시 다음에 13시를 치는 괘종시계가 있는 시계탑 다락방. 시계의 XIII 숫자판 조각이 없어져 시계가 멈췄고, 다락방 문의 시계 자물쇠도 멈췄다. 조각은 수줍음 많은 그림자 유령 똑딱이가 갖고 있다. 놀래키는 장면 없이 어둠·달빛·촛불·거미줄로만 오싹함을 낸다.

**벽 4개**: 북(괘종시계, 시계 자물쇠 문, 모자 상자, 작은 거미) · 동(커튼 친 둥근 창, 책장, 달빛이 들면 나타나는 야광 글씨) · 남(큰 거울, 책상과 서랍, 천을 덮은 안락의자) · 서(낡은 트렁크, 빈 쇠 촛대, 그림자가 나타나는 벽)

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 동쪽 커튼 열기 → 달빛 (방 전체 밤빛 변화) | 환경 변화 | |
| 2 | 달빛에 드러난 야광 글씨: "거울 속 시계만 바른 시간을 말해요" | 관찰 | |
| 3 | 괘종시계는 숫자가 거꾸로 돌고 로마 숫자도 뒤집힘 (IV가 VI처럼 보인다) → 남쪽 거울 속 시계는 **4시 20분** | 거울 | 거울은 좌우를 바꾼다. 어두우면 거울에 안 비침 |
| 4 | 서쪽 트렁크 시계 자물쇠: 짧은 바늘·긴 바늘 손잡이로 4:20 → **양초**, **시금치 통조림** | 논리 | 시계 읽기 (긴 바늘 IV = 20분) |
| 5 | 남쪽 책상 서랍 **성냥** + 양초 = **켜진 양초** | 조합 | |
| 6 | 서쪽 벽의 소곤거림 "불빛이 있으면 내 그림자라도…" → 빈 촛대에 켜진 양초 → 벽에 그림자 유령 | 그림자·환경 변화 | |
| 7 | 똑딱이: "시계가 제일 싫어하는 채소는?" → 시금치 통조림을 건넨다 → **XIII 조각** | 넌센스 | 시(時) + 금지 = 시금치 |
| 8 | 괘종시계 빈 자리에 XIII → 13번 종이 울리고 시계추가 흔들리며 문이 열림 | 관찰 | |

## 4장 거꾸로 된 세상 (설계)

**이야기**: 문을 열었더니 천장이 바닥인 방. 의자, 탁자, 샹들리에가 모두 거꾸로다.

1. **거꾸로 숫자**: 벽 액자 "6 1 8"은 방을 뒤집어 보면 "8 1 9". 방 그림 속 액자 고리가 아래에 있는 것으로 단서. (관찰)
2. 우산 + 끈 = 거꾸로 매단 **우산 그릇**. 위로 떨어지는 빗방울을 받는다. (예상 밖의 쓰임)
3. 우산에 모인 물을 거꾸로 된 화분에 → 뿌리가 위로 자라 천장(바닥) 틈을 가리키고, 그 틈에 **레버 손잡이**.
4. **환경 변화**: 레버를 당기면 방이 180도 회전 (애니메이션). 이제 가구는 바르게, 아까 천장에 붙어 있던 물건들이 바닥으로 떨어진다.
5. 떨어진 물건 중 모래시계: 뒤집으면 모래가 위로 흐름 → 다시 뒤집어야 시간이 간다. 모래시계 받침에 문 코드.
6. 넌센스: "거꾸로 서 있는 사람이 가장 좋아하는 과일은? → 거꾸로 해도 같은 '토마토'". 과일 그릇에서 토마토 → 반으로 자르면 열쇠.

## 5장 바닷속 우체국 (설계)

**이야기**: 바다 밑 우체국에 도착한 거품 편지. 받는 사람 주소가 지워져 있다. 문어 우체국장을 도와 편지를 배달하면 수면으로 올라가는 문이 열린다.

1. 해파리 등불 두 개를 켜면 **환경 변화**: 어두운 선반의 우편함 번호가 보임.
2. 소라 껍데기를 귀에 대면(아이템 살펴보기) 작은 목소리 "내 집은 별 다섯, 달 하나". (관찰·청각 단서를 글로)
3. 바다 생물 우표 표: 불가사리=5, 달=1 … → 주소 **51번 우편함**. (논리)
4. **그림자**: 지나가는 물고기 떼 그림자가 바닥에 화살표를 그림 → 숨은 우편함 위치.
5. 갈고리 + 미역 줄 = **해초 갈고리**, 산호 틈에 끼인 우편함 열쇠를 꺼냄. (조합)
6. 우표 대신 쓸 것이 없다 → 조개껍데기를 꾹 눌러 찍으면 우표 모양 도장. (예상 밖의 쓰임)
7. 넌센스: 우체국장 "바다에서 가장 빠른 편지는? → 고래(Go 래) 편지". 정답을 말하면 고래가 와서 문까지 태워 준다.
