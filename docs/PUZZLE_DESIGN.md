# 퍼즐 설계

## 공통 원칙

- 한 방에 퍼즐 8~12단계, 초등학생 기준 15~25분.
- 능력 골고루: 관찰 · 창의(조합) · 넌센스 · 논리 · 공간지각 · 도구 활용.
- 지시서의 다섯 가지 장치를 다섯 방에 나눠 꼭 한 번 이상 쓴다: 거울 글자, 그림자 암호, 아이템 조합, 예상 밖의 쓰임, 환경 변화.
- 단서는 반드시 방 안에 보인다. 정답을 들으면 "아, 그래서!" 하고 납득되어야 한다.
- 막히면 3단계 힌트: ① 어디를 볼지 ② 무엇을 생각할지 ③ 정확히 무엇을 할지.
- 잘못 써도 벌칙 없음. 왜 안 되는지 짧게 알려 준다 ("자석만 던지면 물속으로 사라질 거야").

## 1장 햇살이 멈춘 온실 (구현 완료)

**이야기**: 온실의 해님 기계가 깊이 잠들어 시간이 멈췄다. 해님을 깨워야 꽃이 자라고, 해바라기가 지키는 열쇠로 문을 열 수 있다.

**벽 4개**: 북(문, 해바라기 화단, 큰 화분, 뜨개 바구니, 달팽이 정원사) · 동(작업대, 선반, 숫자 액자) · 남(해님 기계, 안내판) · 서(빗물통, 새장, 도구 걸이)

|---|---|---|---|
| 1 | 북쪽 뜨개 바구니에서 **실타래** | 관찰 | |

## 2장 토끼의 장난감 공방 (구현 완료)

**이야기**: 장난감 장인 토끼 모카의 공방에 놀러 왔는데, 모카가 낮잠을 자는 사이 문이 잠겼다. 문에 붙은 쪽지: "깨우지 마세요… 단, 생일 노래는 예외!"

**벽 4개**: 북(모카의 안락의자, 깜짝 상자, 당근 자물쇠 문, 모카 옆모습 그림) · 동(작업대, 빨간 작업등, 그림자 인형극 무대, 쥐구멍) · 남(커튼 친 창문, 장난감 선반, 치즈 병, 흔들 목마) · 서(재봉틀, 자수 악보, 토마토 바늘꽂이, 반짇고리 통, 마네킹)

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 동쪽 빨간 작업등 켜기 → 인형극 화면에 빛 | 환경 변화 | 그림자는 빛이 있어야 생긴다 |
| 2 | 나무 조각 셋(몸·머리·귀)을 90도씩 돌려 **토끼 그림자** 만들기 → 무대 서랍에서 **고무줄** | 공간지각·그림자 | 카드와 북쪽 벽 모카 그림이 정답 모양 |
| 3 | 남쪽 치즈 병: 뚜껑이 미끄러워 안 열림 → 고무줄을 감아 열기 → **치즈** | 예상 밖의 쓰임 | 실제 생활 요령 |
| 4 | 동쪽 쥐구멍의 생쥐 찍찍이(등 뒤에 손잡이를 숨기고 배고파함)에게 치즈 → **태엽 손잡이** | 관찰 | |
| 5 | 서쪽 바늘꽂이 → **시침핀**, 반짇고리 통 → **실뜯개** | 관찰 | |
| 6 | 북쪽 깜짝 상자: 옆 구멍에 손잡이 끼우기, 원통에 핀 쓰기 | 도구 | 돌려 보면 노래가 끊겨서 핀이 부족함을 알 수 있다 |
| 7 | 서쪽 자수 악보의 별 높이(아래·가운데·위·가운데·아래·위)대로 원통에 핀 꽂고 손잡이 돌리기 | 관찰·논리 | 악보 = 오르골 원통, 줄 3개 = 칸 3줄 |
| 8 | **환경 변화**: 생일 노래 → 깜짝 상자 펑! → 모카가 깨어나고 커튼이 열려 방이 환해짐 | 환경 변화 | 쪽지 "생일 노래는 예외" |
| 9 | 모카: "문 열쇠? 그건… **당근이지!**" → 당근 인형을 받음 (등에 바느질 자국, 속에 딱딱한 것) | 넌센스 | '당근이지' = '당연하지' 말장난 |
| 10 | 당근 인형 + 실뜯개 = **당근 열쇠** → 당근 자물쇠 문 열고 탈출 | 조합 | |

## 3장 열세 번째 시계 (구현 완료)

**이야기**: 밤 12시 다음에 13시를 치는 괘종시계가 있는 시계탑 다락방. 시계의 XIII 숫자판 조각이 없어져 시계가 멈췄고, 다락방 문의 시계 자물쇠도 멈췄다. 조각은 수줍음 많은 그림자 유령 똑딱이가 갖고 있다. 놀래키는 장면 없이 어둠·달빛·촛불·거미줄로만 오싹함을 낸다.

**벽 4개**: 북(괘종시계, 시계 자물쇠 문, 모자 상자, 작은 거미) · 동(커튼 친 둥근 창, 책장, 달빛이 들면 나타나는 야광 글씨) · 남(큰 거울, 책상과 서랍, 천을 덮은 안락의자) · 서(낡은 트렁크, 빈 쇠 촛대, 그림자가 나타나는 벽)

두 갈래가 나중에 합쳐진다: (가) 달빛·거울·시계 읽기 → 트렁크, (나) 양초·거미·작은 열쇠·서랍 → 성냥.

|---|---|---|---|
| 1 | 동쪽 커튼 열기 → 달빛 (방 전체 밤빛 변화) | 환경 변화 | |
| 2 | 달빛에 드러난 야광 글씨: "거울 속 시계만 바른 시간을 말해요" | 관찰 | |
| 3 | 괘종시계는 좌우가 뒤집혀 있다 → 남쪽 거울 속 시계의 짧은 바늘은 **4** | 거울 | 거울은 좌우를 바꾼다. 어두우면 거울에 안 비침 |
| 4 | 서쪽 트렁크 시계 자물쇠: 짧은 바늘 하나만 4에 맞춘다 → **회중시계**, **바늘 꽂힌 실패** | 논리 | 2학년도 읽을 수 있게 "몇 시"만 묻는다 (분 바늘 없음) |
| 5 | 서쪽 선반 끝 **양초** 챙기기 | 관찰 | |
| 6 | 북쪽 작은 거미가 열쇠를 거미줄에 감아 두었다. 거미줄이 끊겨 속상한 거미에게 실패 → **작은 열쇠** | 조합·배려 | 거미는 실이 필요하다 |
| 7 | 남쪽 책상 서랍(자물쇠)을 작은 열쇠로 → **성냥**, 성냥 + 양초 = **켜진 양초** | 조합 | |
| 8 | 서쪽 벽의 소곤거림 "불빛이 있으면 내 그림자라도…" → 빈 촛대에 켜진 양초 → 벽에 그림자 유령 | 그림자·환경 변화 | |
| 9 | 똑딱이: "바늘이 두 개인데 바느질은 못 하고, 얼굴이 있는데 웃지 못하는 것은?" → **회중시계** → **XIII 조각** (실패를 주면 "바느질 할 수 있잖아") | 넌센스 | 시계 바늘, 시계 얼굴(문자판) |
| 10 | 괘종시계 빈 자리에 XIII → 13번 종이 울리며 번쩍임·먼지, 문이 열림 | 관찰 | |

## 4장 거꾸로 된 세상 (구현 완료)

**이야기**: 시계탑 계단을 올라왔더니 방이 통째로 거꾸로다. 박쥐 뒤죽이가 이 방이 좋아서 뒤집어 놓았다. 방을 다시 바로 세워야 문으로 나갈 수 있다.

**만드는 법**: 방은 바르게 선 모습으로 그리고, 뒤집기 전에는 엔진이 방 레이어를 180도 돌려 보여 준다. 레버를 당기면 2.4초 동안 실제로 빙그르르 돈다.

두 갈래가 레버에서 합쳐진다: (가) 액자·금고·토마토·박쥐 → 레버 손잡이, (나) 풍경화·레버 단추판 → 레버 잠금 풀기.

|---|---|---|---|
| 1 | 남쪽 액자 숫자는 618로 보이지만 꽃 그림이 거꾸로다. 쪽지 + 확대 화면의 **"액자 빙글 돌려 보기"** 단추 → **819** | 공간지각 | 직접 돌려 보며 6이 9가 되고 순서도 뒤집히는 걸 본다 |

| 3 | 박쥐 뒤죽이: "거꾸로 읽어도 이름이 똑같은 과일만 먹어" → 사과(과사)·바나나(나나바)는 거절, 토마토 → **레버 손잡이** (남은 미끼 과일은 간식으로 정리) | 넌센스·논리 | 회문 |
| 4 | 서쪽 레버 단추판: 거꾸로 걸린 풍경화 그림 + 빙글 화살표 + 아래 화살표 1·2·3 → 북쪽 풍경화를 머릿속으로 바로 세워 위에서부터 **해 → 구름 → 언덕** | 공간지각 | 틀리면 불이 모두 꺼지고 처음부터 |

## 5장 바닷속 우체국 (구현 완료)

**이야기**: 바닷속 우체국. 문어 우체국장 팔방이가 주소가 지워진 거품 편지를 배달해 달라고 부탁한다. 배달하면 수면으로 올라가는 엘리베이터를 열어 준다. 마지막 장이라 엔딩에서 모든 친구가 인사한다.

## 6장 거인의 책상 (구현)

**이야기**: 바다 위로 올라온 엘리베이터 문이 열리자 다시 종이 냄새가 난다. 이번에는 내가 지우개만큼 작아졌다! 거대한 책상 위, 스케치북에 그려진 종이 문이 다음 길이다. 책상 주인이 접어 둔 종이학 **접이**가 처음으로 말을 건다. 접이는 앞으로 모든 장에 나오는 이야기의 관찰자다. (스케치북 구석에 "봄"이라는 서명이 있다 → 이 책을 만든 사람의 첫 단서)

**상징 장치**: 크기가 뒤집힌 세계. 연필은 기둥, 지우개는 바위, 엎질러진 물은 바다.

**구도**: 접사 렌즈 느낌. 화면 가장자리에 초점이 나간 거대한 연필밥·지우개 가루·연필 끝(앞쪽 틀).

두 갈래가 마지막 문에서 합쳐진다: (가) 빛과 그림자 + 무게, (나) 높이 + 종이접기 + 물 건너기.

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 북쪽 스케치북의 그림 문: 커다란 X가 있고 손잡이가 없다. 구석 쪽지 "그림 문은 끝까지 그려야 열려요. 손잡이까지! — 봄" | 관찰 | |
| 2 | X는 지워지지 않는다. 가장자리가 흐릿하고, 스탠드와 문 사이 연필꽂이에 연필 두 자루가 X자로 엇갈려 있다 → **그림자** | 그림자·관찰 | 불빛 → 엇갈린 연필 → 문 위 X |
| 3 | 스탠드 스위치를 밟아 끄면 X는 사라지지만 깜깜해서 그릴 수 없다 | 환경 변화 | |
| 4 | 서쪽 커튼 끈은 내가 너무 가벼워서 당겨지지 않는다. 클립 상자에서 **클립** → 끈과 책상 끝의 커다란 지우개를 연결 → 지우개를 밀어 떨어뜨리면 그 무게로 커튼이 열린다 | 예상 밖의 쓰임(추) | 나 대신 무거운 것이 당긴다 |
| 5 | 남쪽 책 더미 계단을 올라 내려다보면 책상에 쓰인 거대한 연필 글씨가 읽힌다: "물을 건너려면 종이배!" (가까이선 한 획밖에 안 보임) | 공간지각(높이) | 큰 글씨는 멀리서 |
| 6 | 서쪽 메모지 한 장 → 접이에게 주면 **종이배** | 조합(캐릭터) | 접이 "종이만 있으면 뭐든 접어 줄게" |
| 7 | 동쪽 엎질러진 물웅덩이(나에겐 바다)를 종이배로 건너(붓이 노) 필통 → **몽당 색연필** | 도구 활용 | |
| 8 | 색연필 심이 뭉툭 → 서쪽 연필깎이에 꽂고 손잡이에 매달려 빙글 → **뾰족한 색연필** | 공간지각(크기) | 손 대신 온몸으로 |
| 9 | 스탠드는 끄고 커튼은 열어 햇빛만 → 그림 문에 손잡이를 그린다 → 그림 문이 진짜 문이 된다 | 합류 | 그림자 없는 빛 |

## 7장 구름 세탁소 (구현)

**이야기**: 무지개 끝… 아니, 구름 위 세탁소. 이곳에서 빨아 말린 구름이 날씨가 된다. 주인은 털이 구름인 양 **뭉게**. 다음 장(등대)으로 가는 무지개 다리를 띄워야 한다. 분실물 바구니에서 「봄」이 수놓인 벙어리장갑 → 뭉게: "오래전 꼬마 손님 봄이가 두고 갔어요. 등대 쪽으로 갔죠." (봄의 두 번째 흔적)

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 뭉게: 무지개는 빗구름 + 햇빛. 빗구름은 먼지투성이, 해님은 이불 구름에 가려짐, 도르래 손잡이 분실 | | 목표가 분명하다 |
| 2 | 서쪽 분실물 바구니 → **돋보기**, 벙어리장갑. 도르래 손잡이는 뭉게 말대로 "‘양’이 신는 ‘말’ 속" → 북쪽 빨랫줄 **말무늬 양말** | 관찰·넌센스 | 양 + 말 = 양말 |
| 3 | 동쪽 도르래 구멍에 손잡이 → 이불 구름이 걷히고 **햇빛** (방이 밝아짐) | 도구·환경 변화 | |
| 4 | 북쪽 빨래 바구니의 **먼지 구름** → 세탁 꼬리표 글씨가 너무 작다 → 돋보기와 합치면 **물방울 → 회오리 → 해** | 관찰·도구 | 작은 글씨는 돋보기로 (아이템은 그대로) |
| 5 | 남쪽 선반의 그림 세제(물방울·회오리·해님·눈송이) → 세탁기에 먼지 구름, 꼬리표 순서대로 세제를 부으면 **빗구름** (눈송이는 "겨울 구름 전용") | 논리 | 꼬리표 그림 = 세제 그림 |
| 6 | 남쪽 안내판 "무지개는 해님을 등지고 서야 보여요" → 해(동쪽)를 등진 서쪽 빨랫줄에 빗구름 → **무지개 다리** | 공간지각·과학 | 진짜 무지개도 해를 등지고 본다 |

## 8장 잉크 등대 (구현)

**이야기**: 무지개 끝 밤바다 위 등대. 등대지기 펭귄 **까망이**. 등불이 꺼져 기차역까지의 징검다리가 안 보인다. 등대 일지: "꼬마 손님 봄이가 초록 잉크로 등대를 그려 주고, 겨울잠 자는 곰 역장님께 편지를 전하러 기차역으로 갔다." (봄의 세 번째 흔적)

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 남쪽 걸레 + 서쪽 빗물통 = 젖은 걸레 → 북쪽 렌즈의 먹물 닦기 | 조합 | 마른 걸레로는 번지기만 |
| 2 | 서쪽 망원경 → 기차역의 초록 등불과 그림 표지판 "초록 불 → 등대" | 관찰 | |
| 3 | 선반엔 빨강·파랑·검정뿐. 까망이 "노랑은… 등잔 밑이 어둡다더니" → 등불 받침대 밑 그늘의 노랑 잉크. 파랑 + 노랑 = **초록 잉크** (빨강+노랑=주황, 빨강+파랑=보라, 검정은 어둠) | 색 섞기·넌센스(속담) | 등대의 등잔 밑 |
| 4 | 초록 잉크 → 잉크 통, 등불 손잡이 → 초록 등불이 돌며 바다 위 **징검다리**가 드러난다 | 환경 변화 | 일지 "같은 색 불빛을 보내면 징검다리" |

## 9장 겨울잠 기차역 (구현)

**이야기**: 눈 쌓인 작은 기차역. 곰 역장 **곰곰이**가 겨울잠 중이고, 품에 오래전 봄이가 맡긴 편지가 있다. 편지: "제가 할머니가 되면 손주가 이 책을 펼칠 거예요. 다락방행 기차를 태워 주세요." → **봄은 주인공의 할머니**.

| # | 할 일 | 능력 | 납득 포인트 |
|---|---|---|---|
| 1 | 안내문: 겨울잠 곰은 봄이 왔다고 느껴야 깬다 (따뜻하게 + 꽃 냄새, 큰 소리 금지) | 관찰 | |
| 2 | 눈삽 → 눈 더미 → 석탄 → 난로 (방이 따뜻해짐) | 도구·환경 변화 | |
| 3 | 따뜻해지면 창 성에가 녹고(시간표가 보임) 꽃봉오리가 핀다 → 꽃 | 환경 변화 | 추우면 꽃이 안 핀다 |
| 4 | 꽃 → 곰곰이 "봄이 왔나…? 봄…? 아, 봄이!" → 편지, **기차표** | 넌센스 | 계절 봄 = 이름 봄 |
| 5 | 기차표 도착지 그림(지붕+둥근 창) ↔ 시간표 다락방 = 3번 → 선로 전환기 3 → 곰곰이의 기적 → 기차 | 관찰·논리 | |

## 10장 봄이의 작업실 (구현, 2편 마지막)

**이야기**: 할머니 집 다락방. 어린 봄이가 종이 책을 만들던 작업실. 책의 마지막 장이 비어 있다: "마지막 장은 너를 위해 비워 둘게. 직접 종이를 만들어 꿰매 넣으렴."

| # | 할 일 | 능력 | 납득 포인트 |

| 1 | 벽의 순서 그림(찢기 → 물통 → 뜨기 → 말리기)대로: 습작 휴지통 → 물통(종이죽) → 종이 뜨는 틀 → 창가 빨랫줄 → 새 종이 | 순서·조합 | 진짜 종이 뜨기 과정 |
| 2 | 새 종이 → 접이가 **문 페이지**로 접기 | 캐릭터 조합 | |

| 4 | 책에 문 페이지 + 바늘 → 책 완성 → 바닥 문이 열리고 아래층에서 할머니 목소리 → 엔딩 | 합류 | |
