# 아트 디렉션

## 한 줄 콘셉트

**오래된 동화책 삽화 속 방에 들어온 느낌.** 종이에 펜으로 선을 긋고 수채로 칠한 뒤, 그림자는 판화처럼 빗금으로 넣었다. 방마다 현실에서 한 걸음 비틀린 초현실적인 장치가 하나씩 있다 (잠든 해님 기계, 13시가 있는 시계, 천장에 놓인 의자…).

## 스타일 규칙

| 항목 | 규칙 |
|---|---|
| 선 | 진한 갈색 잉크(#33261c). 완전한 직선·완전한 원 금지, 손으로 그은 듯 살짝 흔들림 |
| 채색 | 평평한 수채. 같은 색 안에서도 종이에 스민 얼룩이 보이게 |
| 그림자 | 빗금(해칭)으로 표현. 빛 방향은 방마다 하나로 통일 |
| 종이 질감 | 화면 전체에 미세한 종이 결(.grain)을 곱하기로 깐다 |
| 시점 | 정면. 뒷벽 + 좁은 좌우 벽 + 원근 바닥 (1600x900, 16:9) |
| 캐릭터 | 작고 순한 얼굴, 점 눈, 볼터치. 과장된 아기 그림체는 피한다 |
| 글자 | 제목 Song Myung, 본문 Gowun Batang. 둘 다 옛 책 느낌의 명조 |
| UI | 종이 꼬리표, 잉크 화살표, 각진 종이 카드. 둥근 알약 버튼 금지 |

## 금지 사항 (지시서 그대로)

- 이모지를 아이템·가구로 쓰기
- CSS 사각형/원만으로 가구 표현
- 웹사이트·관리자 대시보드 같은 화면
- 과도하게 둥근 카드와 버튼
- 무분별한 그라데이션과 네온
- 유아 학습지 같은 디자인
- 클릭 가능한 물건에 테두리·정답 표시
- 텍스트 문제와 객관식 퀴즈에만 의존하는 퍼즐

## 방별 팔레트와 조명

### 1장 햇살이 멈춘 온실 — 밝고 따뜻한
- 팔레트: 테라코타 #c26a42, 철골 초록 #2f4a3a, 잎 #6f9a4f, 해바라기 #f3bf30, 황동 #d4a649, 종이 #f2e7ca
- 조명: 시작은 푸른 저녁(곱하기 #22304f, 62%) → 해님이 깨어나면 3초 동안 금빛 아침으로. 창으로 사선 빛줄기, 공중에 먼지가 반짝임
- 상징 장치: 수면 모자를 쓴 해님 기계

### 2장 토끼의 장난감 공방 — 귀엽고 아기자기한
- 팔레트: 딸기우유 #e9a3a8, 버터 #f4d98b, 민트 #9fcfb9, 원목 #c9965f, 실밥 빨강 #c4473a
- 조명: 작업등 하나가 만드는 따뜻한 원형 빛. 램프를 옮기면 그림자가 바뀜
- 상징 장치: 스스로 바느질하는 재봉틀

### 3장 열세 번째 시계 — 은은하게 오싹한
- 팔레트: 밤 남색 #1f2742, 촛불 #f2c46b, 빛바랜 자주 #6c4a6e, 녹슨 동 #8a6a3c, 달빛 #cfe0e6
- 조명: 촛불 하나 + 창 너머 달빛. 어두운 구석은 빗금으로 깊게. 놀래키는 연출 없이 '조용히 이상한' 느낌
- 상징 장치: 숫자가 13까지 있는 괘종시계, 수줍은 그림자 유령

### 4장 거꾸로 된 세상 — 기발하고 초현실적인
- 팔레트: 하늘 #9cc6e4, 구름 #f7f3ea, 레몬 #f0d64a, 체리 #d2444f, 잉크 보라 #5a4a8a
- 조명: 아래(천장 쪽)에서 위로 비치는 빛. 그림자가 거꾸로 떨어짐
- 상징 장치: 천장에 붙은 가구, 위로 흐르는 물

### 5장 바닷속 우체국 — 신비롭고 몽환적인
- 팔레트: 심해 청록 #1d4d5a, 물빛 #5fa3a8, 산호 #e98a72, 진주 #efe8dc, 해파리 보라 #b59ad6
- 조명: 수면에서 내려오는 일렁이는 빛(코스틱) 애니메이션, 해파리 등불
- 상징 장치: 거품에 담겨 떠다니는 편지, 문어 우체국장

## 움직임

- 매달린 물건은 천천히 흔들림(새장), 캐릭터는 숨 쉬듯 위아래(달팽이, 잠든 해님)
- 큰 변화는 한 번에 크게: 해님이 깨면 하늘·벽·꽃·빛줄기가 함께 3초에 걸쳐 바뀜
- 아이템을 주우면 그 자리에서 가방 꼬리표로 날아감
- `prefers-reduced-motion` 사용자는 모든 애니메이션 정지
