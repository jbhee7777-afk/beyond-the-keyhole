# 3편 「종이의 뒷면」 설계 (11~15장)

> 1·2편보다 **어른 기준으로 한 단계 어렵게**, **진짜 세상의 원리로 푸는 창의적인 퍼즐**, **도형 조합이 아닌 디테일한 손그림**.
> 그림 → 배치 → 퍼즐 구현 순서로 만든다. 이 문서는 그림을 뽑기 전에 정하는 "설계도"다.

## 이야기

2편 끝에서 할머니(봄)가 완성된 종이 책을 건네준다. 그날 밤, 마지막 장 뒤쪽에서 잉크가 **거꾸로 배어 나온다**. 누군가 종이 **뒷면**에서 글씨를 쓰고 있다.

> "앞면이 다 채워지면, 뒷면은 지워져요. 실이 풀리기 전에 와 주세요."

책의 뒷면에는 앞면에 그려지지 못한 것들이 산다. 제본사 나방 **모리**가 주인공을 부른다.
뒷면 세계를 붙잡아 두는 다섯 가지가 하나씩 사라지고 있다: **실(제본) · 물(물자국) · 빛(별) · 그림자 · 접힘**.
다섯 방을 지나며 하나씩 되찾으면, 앞면과 뒷면이 한 장으로 이어진다.

분위기: 1·2편보다 차분하고 쓸쓸하고 신비롭다. 무섭지는 않다(잔혹·깜짝 공포 금지 원칙 유지). 어른이 봐도 "예쁘다, 잘 만들었다"는 소리가 나오는 밀도.

## 난이도 원칙 (1·2편과 무엇이 다른가)

| | 1·2편 | 3편 |
|---|---|---|
| 한 방 단계 | 8~12 | **12~16**, 그중 2~3개는 여러 벽의 단서를 합쳐야 풀림 |
| 단서 | 쓸 곳 바로 옆 | 다른 벽, 확대 화면, 수첩에 적힌 것을 **기억·대조** |
| 정답 안내 | 독백이 거의 알려 줌 | 독백은 관찰만 말함. 결론은 플레이어가 낸다 |
| 미끼 | 거의 없음 | 그럴듯한 미끼 1~2개 (틀리면 **왜** 틀렸는지 알려 줌) |
| 풀이 방식 | 조합·순서 | **실제 원리**: 제본의 순서 표시, 비침 무늬, 거울 활자, 온도 섞기, 소리 높이, 그림자 크기, 색 필터, 접어서 맞닿기 |
| 힌트 | 3단계 | 3단계 유지. 1단계는 "어디를 볼지"만, 3단계에서만 정답 |

공정함: 정답을 들으면 반드시 "아, 그래서!"가 나와야 한다. 무작위 시도, 바깥 지식(언어·수학 공식) 요구 금지. 숫자 계산은 덧셈·비율 정도.

## 그림 원칙 (3편 전용)

- **도형 조합 절대 금지.** 모든 배경·소품은 이미지 생성 도구로 디테일한 손그림(펜 선 + 빗금 + 수채)으로 먼저 "설계 그림"을 뽑고, 그 그림을 기준으로 배치한다.
- 한 방 = 네 벽 배경 + 상태가 바뀌는 소품(열림/닫힘 등) + 확대 화면 + 아이템 + 캐릭터.
- 같은 방의 그림은 **첫 배경을 참조 이미지로** 넣어 화풍·조명·색을 맞춘다.
- 상태가 바뀌는 소품은 배경과 따로 그려 배경 제거 후 PNG로 올린다. 클릭 영역(hit)은 그림 위에 직접 잡는다(테두리·정답 표시 금지 원칙 유지).
- 그림 속 글자 금지(기기·언어 문제). 숫자·글자가 필요한 단서는 그림 기호로.
- 팔레트: 밤의 제본소(호박·고동·청록·촛불 금색) → 찻집(김 서린 청자·구리) → 천문대(남색·황동·별빛) → 그림자 극장(검정·주홍·양초 빛) → 접히는 집(흰 종이·접힌 그늘·새벽 분홍).

## 11장 한밤의 제본소 — 되찾을 것: 실

**캐릭터**: 나방 제본사 **모리** (큰 더듬이, 털 목도리 같은 가슴털, 작은 안경, 소심함).
**방**: 다락 제본소. 북: 제본 작업대와 책 누르개(프레스). 동: 달빛 둥근 창과 말리는 접장(종이 묶음)들. 남: 활자 상자와 금박 도구. 서: 고치가 매달린 대들보와 실 선반.

| # | 할 일 | 원리 · 납득 포인트 | 단서 위치 |
|---|---|---|---|
| 1 | 빨랫줄에 널린 **접장 6묶음**을 걷는다 | | 동 |
| 2 | 접장을 순서대로 쌓기: 등(접힌 쪽)에 찍힌 **작은 검은 칸**이 계단처럼 대각선이 되게 | 실제 제본의 "순서 표시(collation mark)". 페이지 번호가 없어도 등의 표시만 보면 순서가 맞는지 안다 | 작업대 위 완성된 책의 등 확대 → 비스듬한 줄이 보인다 |
| 3 | 실이 없다. 모리: "제 실은… 다 썼어요" → 대들보의 **빈 고치**에서 비단실을 풀어낸다. 손이 안 닿음 → 책 누르개의 **나사 손잡이**를 빼서 갈고리처럼 | 나방 = 누에 친척. 예상 밖의 쓰임 | 서 |
| 4 | 비단실은 미끄러워 꿰맬 수 없다 → **촛농(밀랍)** 에 문질러 밀랍 실 | 진짜 제본용 실은 밀랍을 먹인다 | 북 작업대의 밀랍 덩어리 자국 + 모리의 혼잣말 |
| 5 | 바늘은 **바늘꽂이 고슴도치** 속. 바늘꽂이를 확대해 핀 사이에 끼인 것 하나만 바늘(귀가 있음) | 관찰 (핀 7개 중 귀 있는 것) | 남 |
| 6 | 꿰매기 틀: 접장 + 밀랍 실 + 바늘 → 책 몸통 | 조합 | 북 |
| 7 | 표지 종이는 백지. 달빛 창에 대 보면 **비침 무늬(워터마크)** 로 나방 문양과 **별 세 개**가 보인다 | 종이를 빛에 비추면 보이는 물자국 | 동 창 (구름이 가리고 있음 → 8번 먼저) |
| 8 | 창 앞 구름: 남쪽 **풀무**로 바람 → 구름이 비켜 달빛 | 환경 변화 | 남 |
| 9 | 활자 상자(그림 활자 12개)에서 표지 제목 찍기: 워터마크와 같은 문양 순서. 단 **활자는 거울 글씨** → 좌우 뒤집힌 활자를 **오른쪽부터** 놓아야 바르게 찍힌다 | 도장·활자는 거꾸로 새긴다. 미끼: 바로 선 활자는 찍으면 뒤집혀 나온다 | 남 확대 위젯 |
| 10 | 금박: 금박 종이 + 데운 활자(초) → 표지 | 조합 | 남 |
| 11 | 책 몸통 + 표지 → 책 누르개에 넣고 나사(3번에서 뺀 것) 다시 끼워 돌리기 | 앞에서 빼 쓴 물건을 제자리로 | 북 |
| 12 | 완성된 책을 모리에게 → 모리가 날개를 펴 **책 등의 실**을 뒷면 세계로 이어 줌 → 서쪽 벽 책장이 문처럼 열림 | | 북·서 |

미끼: 핀(귀 없음), 바로 선 활자, 털실(굵어서 바늘귀에 안 들어감).
엔딩 대사: 모리 "실이 다시 이어졌어요. 다음 쪽은… 물이 마르고 있어요."

## 12장 김 서린 찻집 — 되찾을 것: 물

**캐릭터**: 수달 찻집 주인 **달래** (앞치마, 젖은 수염, 느긋함).
**장치**:
- **김 서린 유리**: 주전자 김을 쐬면 유리에 손가락으로 썼던 그림이 떠오른다 (입김 글씨 원리).
- **온도 맞추기**: 차는 60도. 끓는 물(100) 한 컵 + 찬물(20) 한 컵 = 60. 계량컵 두 개와 온도계. 미끼: 끓는 물 그대로 → "잎이 타서 써요".
- **물잔 실로폰**: 벽의 악보가 "물 높이 그림"으로 그려져 있다. 물을 따라 잔 높이를 맞추고 치면 문이 열리는 음. 물이 많을수록 낮은 소리 (실제 원리).
- **찻잎 점**: 마신 찻잔 바닥의 찻잎 모양이 열쇠 위치 그림 (주전자 → 몇 번째 서랍).
- 결론: 마른 물자국(얼룩) 지도에 물을 떨어뜨리면 번지며 길이 이어진다 → 물을 되찾음.

## 13장 태엽 천문대 — 되찾을 것: 빛(별)

**캐릭터**: 부엉이 천문 박사 **휘** (눈이 커서 낮엔 졸림).
**장치**:
- **오리러리(태엽 행성 모형)**: 손잡이 1바퀴에 안쪽 별은 1칸, 가운데는 1/2칸, 바깥은 1/3칸. 세 별을 한 줄에 세우려면 몇 바퀴? → 기록지의 "지난번 한 줄로 선 날" 그림과 비교 (어른 난이도: 비율 맞추기).
- **달의 모양 달력**: 창밖 달 모양 → 달력 그림에서 오늘을 찾는다.
- **별자리 잇기**: 1·2편 동물 친구들이 별자리로 숨어 있다 (모카·찍찍이·뭉게·까망이·곰곰이). 별 망원경으로 하나씩 찾는다 = 시리즈 보상.
- **렌즈 두 개 망원경**: 볼록 렌즈 두 개의 거리를 맞춰야 초점 → 서랍의 작은 별 지도 읽힘.

## 14장 그림자 인형극장 — 되찾을 것: 그림자

**캐릭터**: 그림자만 있는 배우 **너울** (몸이 없음, 무대 막에만 보임).
**장치**:
- **그림자 크기**: 촛불에 가까울수록 그림자가 크다. 대본 그림의 "커다란 늑대"를 만들려면 작은 인형을 촛불 쪽으로.
- **손 그림자 합치기**: 인형 둘을 겹쳐 세 번째 모양 (토끼 + 나뭇가지 = 사슴).
- **색 필터 대본**: 빨간 셀로판을 대면 빨간 낙서가 사라지고 파란 글씨(그림)만 남는다 — 비밀 지시.
- **막 뒤 순서**: 공연 포스터 네 컷 순서대로 인형을 세우면 너울이 몸(그림자)을 되찾는다.

## 15장 접히는 집 — 되찾을 것: 접힘 (3편 마지막)

**캐릭터**: 모리·달래·휘·너울과 접이가 함께.
**장치**:
- **접어 맞추기 그림(fold-in)**: 벽 포스터를 표시대로 접으면 그림 두 개가 합쳐져 숨은 장면이 나온다.
- **지도 접기 = 지름길**: 먼 두 점을 종이를 접어 맞닿게 하면 건너갈 수 있다 (종이 세계의 웜홀).
- **앞면·뒷면 맞추기**: 한 장의 앞뒤 그림이 비침으로 겹쳐질 때만 완성되는 열쇠 (11장 비침 무늬 회수).
- 다섯 방에서 되찾은 실·물·별·그림자·접힘을 책에 넣고 마지막 장을 접어 닫는다 → 앞면 세계(할머니 부엌)와 이어지는 엔딩.
